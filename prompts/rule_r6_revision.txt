Do NOT create a dimension or a characteristic that no classified object would have. The number of objects under each characteristic is shown in the taxonomy, together with the objects that fit no characteristic. Create a new element only by reorganizing what exists (split, merge, promote, demote) or for objects that are already classified and fit no characteristic; every new characteristic must have objects among them. Where a perspective or a dimension lacks elements and no classified object supports them, change nothing: that needs new evidence, which is not decided here. Return an empty list when no adjustment is justified.
